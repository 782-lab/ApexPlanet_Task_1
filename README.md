
# WebCraft - Learn Web Development

A beginner-friendly and responsive webpage developed using HTML5, CSS3 and JavaScript as part of the 45-day Web Development Internship at ApexPlanet Software Pvt. Ltd.

## Project Overview

WebCraft is an introductory web development webpage designed to demonstrate the fundamental concepts of frontend development.

It explains how HTML, CSS and JavaScript work together to create interactive and visually appealing websites.

## Internship Details

- Company: ApexPlanet Software Pvt. Ltd.
- Domain: Web Development
- Duration: 45 Days
- Task: Task 1 - Basics of Web Development
- Technologies: HTML5, CSS3 and JavaScript

## Features

- Semantic HTML5 structure.
- Professional navigation bar.
- Hero section with an image.
- About Web Development section.
- HTML, CSS and JavaScript technology cards.
- Developer introduction section.
- Interactive JavaScript welcome button.
- External documentation links.
- Responsive layout for mobile, tablet and desktop.
- CSS hover effects and smooth scrolling.

## Technologies Used

### HTML5
Used to create the webpage structure and semantic elements.

### CSS3
Used for styling, typography, colors, layouts and responsive design.

### JavaScript
Used to implement button interactions and browser alert functionality.

## How to Run Locally

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder in VS Code.

3. Install the Live Server extension.

4. Right-click index.html.

5. Select Open with Live Server.

6. Open the website in your browser.
